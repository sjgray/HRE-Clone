8296 High-Res Emulator (HRE) board clones
=========================================

These are clones of the Commodore 8296 High-Res Emulator (HRE) board. The HRE
is a board plus firmware that emulates the Commodore High-Speed Grahic (HSG)
board which contains a Thomson EF Video Display Processor (VDP). The HRE
firmware implements the same BASIC commands as the HSG but does the drawing
with the 6502 processor rather than the VDP chip.

This is a work-in-progress. It is being cloned using Kicad and some pictures
of the board. The boards are complete but untested. Use at own risk!

PCB........ Kicad Files (work in progress)
   Clone... Original PCB recreation
   Mini.... Compacted version
Firmware... Binary files for Option ROM sockets
Pics....... Renders and (eventually) PCB pics
Software... Demos etc
