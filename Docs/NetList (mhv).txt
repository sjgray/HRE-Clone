Note:
Why is PA0 used? What's about the highest data bit (D7), because the addresses at the chargen
is only 7 bit. The highest bit is used for the reverse characters! This bit is available
onboard at a pad via UD4 Pin2. Is this connected to PA0 from the userport? If this connection
is make, never switch this userport bit to output!

Note:
U6 Pin 21 goes to the clear input of a onboard flip flop (UD4 Pin 1). This flip flop stores the
reverse state. If the graphics board put this pin to low, is disabled the reverse state.
So in hires mode this pin must be low! But who drives this?

Note:
U10 Pin 25 is the /CS for the original CRTC. This mask all addresses from E880 to E8FF. The
register on the graphics board has addess E888. From where come A3?
